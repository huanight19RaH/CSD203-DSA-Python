## 📌 Overview

This repository archives Python source code and problem solutions for the **CSD203 (Data Structures & Algorithms)** curriculum. It serves as both a reference handbook for core data structures and an exam-preparation guide featuring verified practical exam problems across multiple academic semesters (SU24, FA24, SU25).

## 🧠 Topics Covered

### 1. Linear Data Structures
- **Singly Linked List (`MyList`)**: Append, Prepend, Insert at position, Delete by key, Reverse list, Sort by attribute.
- **Stack & Queue**: LIFO and FIFO implementations for auxiliary traversals.

### 2. Tree Structures
- **Binary Search Tree (`BSTree`)**:
  - Insert, Search, Minimum / Maximum queries.
  - Tree Traversals: Breadth-First Search (BFS via Queue), In-Order, Pre-Order, Post-Order.
  - Deletion algorithms: Delete by copying, Delete by merging.
  - Tree Height & Balance checks.

### 3. Graph Algorithms
- Adjacency Matrix & Adjacency List representations.
- Breadth-First Search (BFS) & Depth-First Search (DFS).
- Shortest path finding with Dijkstra's Algorithm.
- Minimum Spanning Tree (MST) & Euler Cycles.

### 4. Sorting & Searching
- Bubble Sort, Selection Sort, Insertion Sort, Quick Sort, Merge Sort.
- Binary Search & Linear Search.
